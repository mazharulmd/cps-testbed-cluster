# Paper: GridPACK–NS-3–HELICS testbed (IEEE Access manuscript)

"A Remotely Accessible GridPACK–NS-3–HELICS Testbed for Synchrophasor-Based Monitoring
and Control Under Cyber Attacks". Md Mazharul Islam, Sunjare Zulfiker, Masum Reza and
Hafiz Abdur Rahman, North South University.

## Layout

| Path | Contents |
|---|---|
| `main.tex` | manuscript |
| `references.bib` | references; one entry per row of the literature review sheet (column *Key*) |
| `figures/` | one file per figure (PDF, or PNG at 300 dpi for dashboard screenshots) |
| `tables/` | result tables generated by `scripts/make_tables.py` |
| `data/` | per-run metrics and time series extracted from the runs |
| `campaign/paper118_seeds.yaml` | the 225 experiments of the paper |
| `scripts/` | everything that produces `data/`, `tables/` and `figures/` |

## Reproducing the results

1. Start the testbed (virtual cluster or native install) and submit the campaign:
   ```
   cd paper/scripts
   python split_campaign.py ../campaign/paper118_seeds.yaml
   for f in part*.yaml; do curl -u admin -F file=@$f http://<head>:8080/api/scenarios/file; done
   ```
2. When the queue is empty, extract the metrics from the run directory:
   ```
   python extract_results.py /srv/cps/runs ../data
   ```
3. Time the estimator (testbed Python environment, from the repository root):
   ```
   python paper/scripts/bench_estimator.py 200 > paper/data/bench_estimator.csv
   ```
4. Build figures and tables, then the PDF:
   ```
   python make_figures.py && python make_tables.py && ./build_diagrams.sh
   cd .. && pdflatex main && bibtex main && pdflatex main && pdflatex main
   ```

The dashboard screenshots (`fig_dashboard_*.png`) were captured from the running
dashboard during IEEE 118-bus runs. They are the only figures not drawn by a script.

## Template

`main.tex` uses `IEEEtran` in journal mode so that it compiles with a standard TeX Live.
Before submission, move the text into the official IEEE Access LaTeX template
(`ieeeaccess.cls`, from the IEEE Author Center). The sections, figures, tables and
bibliography carry over unchanged; the front matter needs the template's `\history`,
`\doi`, `\corresp` and `\tfootnote` fields and author photos for the biographies.
